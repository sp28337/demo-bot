# Telegram Bot — aiogram Learning Project

This is my **first Telegram bot**, created while learning **aiogram** with the help of YouTube video lessons.  
The project was built to understand how Telegram bots work and how to interact with the Telegram Bot API using Python.

During development, I explored core concepts such as **bot initialization, message handling, commands, environment configuration, keyboards, callback handlers and basic validation**.
This repository represents my entry point into Telegram bot development using **aiogram**.

## Tech Stack

- Python 3.12
- aiogram
- Pydantic Settings
- dotenv
